# TasteAdvisor

Implementation of a Ruby On Rails Web Application.
The app folder contains all the files within the Model-View-Controller Framework. The remaining folders contain instead necessary graphic (e.g. the Navigation bar) and structural (e.g. the databasr) utilities.

LASSI Project. Authors: Lorenzo Pecorari, Giorgio Paoloni, Gianluca Scanu, Leonardo Mugnetti.
